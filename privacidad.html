Política de Privacidad de MochilaLista

Última actualización: 20 de noviembre de 2026 • Paquete Android: com.mochilalista.app

1. Responsable y Titular de la Aplicación

La aplicación móvil MochilaLista (identificador de paquete com.mochilalista.app) es desarrollada y operada por Julio Angello Vasquez Navarro (Perú). Esta Política de Privacidad describe cómo se recopilan, almacenan y protegen los datos cuando utilizas la aplicación, en conformidad con la Ley N.° 29733 (Ley de Protección de Datos Personales del Perú) y las políticas de datos de usuario de Google.

2. Arquitectura Offline-First (Datos Locales en tu Dispositivo)

MochilaLista funciona principalmente de manera local (Offline-First). Toda la información de tu negocio —productos, inventario, ventas, cotizaciones, clientes y perfiles comerciales— se almacena directamente en una base de datos SQLite local en tu teléfono. El desarrollador no opera servidores centrales que recopilen, lean o almacenen las ventas ni los registros comerciales de tu negocio.

3. Uso de Datos de Usuario de Google y Google Drive API

De forma completamente opcional, el usuario puede vincular su cuenta de Google para respaldar y restaurar la base de datos de su negocio en Google Drive.

Permiso utilizado: MochilaLista solicita únicamente el alcance no sensible https://www.googleapis.com/auth/drive.appdata (carpeta privada de datos de aplicación en Google Drive) y la información básica de identificación de la cuenta (correo electrónico) para mostrar qué cuenta está vinculada.
  • Finalidad exclusiva: Crear, listar y restaurar copias de seguridad cifradas (.mlbg, cifradas localmente con AES-256-GCM) dentro de la carpeta privada oculta de la aplicación en el propio Google Drive del usuario.
  • Sin acceso a archivos personales: MochilaLista NO puede ver, leer, modificar ni eliminar ningún otro archivo, carpeta, documento o foto almacenado en tu Google Drive.
  • Cero venta o compartición: No vendemos, alquilamos ni transferimos datos de usuario de Google a terceros, anunciantes ni corredores de datos.
  • Cumplimiento de Uso Limitado de Google: El uso y la transferencia de información recibida de las API de Google por parte de MochilaLista se adherirán estrictamente a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado (Limited Use).

4. Permisos del Dispositivo y Funciones Opcionales

  • Cámara y Galería: Se utilizan únicamente cuando el usuario elige tomar o seleccionar una foto para escanear códigos de barras, códigos QR de licencia o digitalizar facturas/listas mediante el escáner inteligente.
  • Procesamiento de Escaneo con IA: Cuando el usuario utiliza voluntariamente el escaneo de listas o facturas con IA, únicamente la imagen seleccionada se envía al servicio de Google Gemini API para extraer los ítems solicitados, sin almacenarla en servidores del desarrollador.
  • Identificador Técnico del Dispositivo: Para gestionar la activación offline de licencias se genera un código hash local derivado del identificador de aplicación Android (no se recopila ni se solicita el IMEI del equipo).
  • Bluetooth: Se utiliza exclusivamente si el usuario decide conectar una impresora térmica local para emitir comprobantes.

5. Seguridad, Retención y Eliminación de Datos

  • Cifrado local y en la nube: Las copias de seguridad subidas a Google Drive se cifran con AES-256-GCM antes de salir del dispositivo. La aplicación conserva un máximo de las últimas 5 copias fechadas en tu carpeta privada appDataFolder.
  • Control total del usuario: Puedes desvincular tu cuenta de Google en cualquier momento desde la sección Respaldos y Seguridad dentro de la app, eliminar tus datos locales desde el dispositivo o revocar el acceso de MochilaLista directamente desde los ajustes de seguridad de tu cuenta de Google (myaccount.google.com/permissions).
  • Al desinstalar la aplicación: Los datos locales almacenados en el teléfono son eliminados por el sistema operativo Android. Las copias que hayas guardado previamente en tu Google Drive permanecen bajo tu exclusivo control hasta que decidas restaurarlas o eliminarlas desde tu cuenta.

6. Cambios en esta Política

Podemos actualizar esta Política de Privacidad periódicamente para reflejar mejoras técnicas o requisitos legales. Cualquier cambio será publicado en esta misma dirección web con la fecha de actualización correspondiente.
